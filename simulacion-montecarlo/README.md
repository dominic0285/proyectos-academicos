# 🎲 Simulación Monte Carlo — Políticas de mantenimiento

Programa en Python que compara, mediante **simulación Monte Carlo**, dos políticas de reemplazo de piezas en un centro mecánico:

- **Política A**: reemplazar solo la pieza que falla.
- **Política B**: cuando falla una, reemplazar las tres a la vez.

Estima para cada política el **costo promedio**, el tiempo de cambio, el tiempo de retardo y la inactividad del centro y muestra los resultados por consola.

```bash
pip install numpy
python simulacion_montecarlo.py
```
