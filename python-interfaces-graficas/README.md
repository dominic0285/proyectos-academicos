# 🐍 Aplicaciones de escritorio en Python (Tkinter + Matplotlib)

Colección de programas con interfaz gráfica hechos en Python.

| Archivo | Qué hace |
|---|---|
| `grafico_ventas_barras.py` | Ingresa categorías, cantidades y precios; genera un gráfico de barras de ventas con totales. |
| `grafico_torta_categorias.py` | Gráfico de torta a partir de categorías y valores ingresados (ignora campos vacíos). |
| `triangulo_color_aleatorio.py` | Triángulo que cambia a un color aleatorio con cada clic (eventos de Tkinter). |
| `arbol_fractal_turtle.py` | Árbol fractal dibujado con **recursividad** usando Turtle. |

## Cómo ejecutarlos
```bash
pip install matplotlib
python grafico_ventas_barras.py
```
Para crear un ejecutable: `pip install pyinstaller` → `pyinstaller --onefile --windowed archivo.py`.
