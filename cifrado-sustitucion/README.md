# 🔤 Cifrado por sustitución con clave

Aplicación de escritorio (Python + Tkinter) que **cifra y descifra mensajes** sustituyendo cada letra por un código de símbolos (`A → 1!`, `B → 2@`…). La tabla de códigos se reorganiza según una palabra clave, así que el mismo mensaje produce resultados distintos con claves distintas. El descifrado usa la tabla inversa.

```bash
python cifrado.py
```
